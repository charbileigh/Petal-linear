# Petal Linear

Petal Linear is a responsive, installable task manager inspired by the speed and clarity of modern product-management tools. It uses a pink light theme and a purple dark theme.

## Features

- Board and list task views
- Create, edit, delete, search, filter, and drag tasks between statuses
- Projects, priorities, due dates, and progress tracking
- Keyboard shortcuts for search and task creation
- Installable PWA with offline app-shell support
- Device-local task and theme persistence
- Responsive desktop and mobile layouts

## Run locally

Serve the repository root with any static web server. For example:

```bash
npx serve .
```

## GitHub Pages

After merging, enable GitHub Pages for the repository and publish from the `main` branch root. The relative asset and service-worker paths are ready for project-site hosting.

Task data is stored in the browser and does not sync across devices.
